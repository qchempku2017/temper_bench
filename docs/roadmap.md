# Roadmap

[Back to the project overview](../README.md) · [Data format and grouping](data-format.md) · [Data splitting](data-splitting.md)

Planned capabilities include:

- a web platform for uploading custom datasets;
- a web UI for creating dataset information and grouping metadata, including automatic information-field filling from uploaded files;
- an online train-test split repository;
- results uploading; and
- benchmarking-results visualization.

The current input conventions are documented in [Data format and grouping](data-format.md), and the implemented split workflow is documented in [Data splitting](data-splitting.md).
